# ข้อเสนอขอบเขตสิทธิ์สำหรับการแจกฟรี — ยังไม่มีผลเป็น license

`LICENSE` หลักยังเป็น Proprietary ฉบับเดิม ข้อเสนอนี้เตรียมไว้ให้เจ้าของตรวจและเลือก
ไม่ใช่การเปลี่ยนสิทธิ์ในซอร์สหรือการให้สัญญาแทนเจ้าของแล้ว

ข้อเสนอที่สอดคล้องกับการแจกฟรีโดยยังสงวนซอร์ส:

- อนุญาตให้ดาวน์โหลด ติดตั้ง build จากซอร์ส และใช้งานโดยไม่คิดค่าใช้จ่าย
- ระบุให้ชัดว่าใช้ส่วนบุคคลเท่านั้น หรือรวมการใช้ภายในองค์กร/เชิงพาณิชย์ด้วย
- แยกสิทธิ์ใช้แอปจากสิทธิ์แก้ไขซอร์ส แจกสำเนา ทำ fork ภายนอกแพลตฟอร์ม
  ใช้แบรนด์ หรือออก derivative product; ให้เจ้าของเลือกสิทธิ์ที่ต้องการจริง
- ไม่จำกัดสิทธิ์ที่ผู้รับมีอยู่แล้วตาม license ของ third-party components,
  GitHub platform terms หรือกฎหมายที่ใช้บังคับ
- ระบุว่า permission นี้ไม่ให้สิทธิ์ในสื่อ บัญชี เครื่องหมายการค้า หรือระบบของแพลตฟอร์มอื่น
- ทบทวน warranty/liability/termination/กฎหมายที่ใช้ และข้อความทุกภาษาก่อนทำเป็นสัญญาจริง

ไม่เสนอให้เปลี่ยนทั้งโครงการเป็น GPL เพียงเพราะใช้ FFmpeg และไม่เสนอให้เรียก
การแจกฟรีภายใต้ Proprietary ว่าเป็น open source โดยอัตโนมัติ
