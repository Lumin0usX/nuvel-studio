YTDL STUDIO
===========

เปิดแอปโดยไม่มี Terminal
Windows: ดับเบิลคลิก shortcut "YTDL Studio" ในโฟลเดอร์โปรเจกต์
ถ้ายังไม่มี shortcut ให้รัน install.bat หรือ python create_windows_launcher.py หนึ่งครั้ง
macOS: รัน install_macos.command แล้วเปิด "YTDL Studio Launcher.app"
เก็บ launcher ของ Mac ไว้ในโฟลเดอร์โปรเจกต์ ใช้ alias หรือ Dock แทนการย้ายตัว launcher
อัปเดต source ตามเดิม ตัวติดตั้ง/ตัวอัปเดตจะสร้าง launcher ให้ ไม่ต้อง build แอปแบบแพ็กแยก
ปิดหน้าต่างแอปแล้วโปรเซสลูกของ session จะหยุดด้วย ถ้ามีงานอยู่จะถามยืนยันก่อน
Windows logs: %LOCALAPPDATA%\YTDLStudio\logs
macOS logs: ~/Library/Logs/YTDLStudio
start.bat / start_macos.command ยังเก็บไว้สำหรับตรวจข้อผิดพลาดผ่าน Terminal

ข้อมูลรุ่นก่อนและคำแนะนำ classic ด้านล่างอาจไม่ตรงหน้าจอปัจจุบัน ดู README.md เป็นหลัก

LIQUID GLASS UI
หน้าจอหลักใหม่ใช้ WebView พร้อมกระจกโปร่งแสง แสงมุกฟ้า-ลาเวนเดอร์
การ์ด MP4/MP3, แผงโลโก้เลือกดูสถานะ, กิจกรรมล่าสุด และปุ่มหยุดงาน
เป็นดีไซน์แนว Liquid Glass; ไม่ใช่คอมโพเนนต์ Liquid Glass ของ Apple โดยตรง

Windows: เปิด install.bat อีกครั้ง แล้ว start.bat
หากยังไม่มี pywebview จะเปิดหน้าต่างแอปผ่าน Edge/Chrome ที่ติดตั้งอยู่
ระบบดาวน์โหลดทำงานในเครื่องผ่าน 127.0.0.1 ไม่ส่งไฟล์ให้บริการของแอป
โหมดนี้ต้องเปิดหน้าต่าง Terminal ค้างไว้ และพิมพ์เส้นทางโฟลเดอร์ได้ในตั้งค่า
หากต้องการหน้าต่าง native และตัวเลือกไฟล์แบบ native ให้ติดตั้ง pywebview
Windows ต้องมี Microsoft Edge WebView2 Runtime

macOS: รัน bash install_macos.command อีกครั้ง แล้ว bash start_macos.command
หน้าจอ native ใช้ WebKit ผ่าน pywebview และเปิด vibrancy บน macOS
ต้อง build .app ใหม่ด้วย bash build_macos.command เพื่อรวมหน้าจอใหม่

ui/index.html เปิดดูดีไซน์แบบออฟไลน์ได้ แต่ดาวน์โหลดไม่ได้เมื่อเปิดไฟล์ตรง ๆ
ตัวเปิดปกติ ytdl_studio.py จะเชื่อมระบบดาวน์โหลดให้
หน้าจอ Tk รุ่นก่อนเก็บไว้ใน legacy_tk.py เรียกได้ด้วย python ytdl_studio.py --classic

หน้าจอใหม่ไม่เก็บประวัติหรือ cookies ลง storage ของหน้าเว็บ
กิจกรรมล่าสุดแสดงงานสำเร็จสูงสุด 8 งานในรอบการเปิดแอปนี้
การหยุดระหว่างแปลงไฟล์ต้องรอ FFmpeg จบขั้นตอน และอาจเหลือไฟล์บางส่วน

ข้อมูลด้านล่างเป็นคำแนะนำทั่วไปและหน้าจอ classic:

macOS Apple Silicon: ดู README-macOS.md
บน Mac รัน bash install_macos.command แล้ว bash start_macos.command
สร้าง .app บน Mac ด้วย bash build_macos.command

เริ่มใช้งาน
1. ติดตั้ง Python 3 พร้อม Tcl/Tk และเลือก Add Python to PATH
2. เปิด install.bat เพื่อติดตั้งหรืออัปเดต yt-dlp และ FFmpeg
3. เปิด start.bat
4. วางลิงก์คลิป เลือก MP4 หรือ MP3 และโฟลเดอร์ แล้วเริ่มดาวน์โหลด

แพลตฟอร์ม
แผงด้านขวาตรวจตัวรองรับจาก yt-dlp ที่ติดตั้งจริงเมื่อเปิดโปรแกรม
แสดง YouTube, TikTok, Facebook, Instagram, X, Reddit, Vimeo,
Dailymotion, Twitch (Clips), Bilibili และ Pinterest
สีเขียว: มีตัวรองรับ / สีส้ม: ตัวรองรับระบุว่ามีปัญหา / สีชมพู: ไม่พบ
สถานะนี้ไม่ใช่ผลทดสอบเครือข่ายหรือการรับประกันว่าทุกคลิปดาวน์โหลดได้
เว็บอื่นยังรับผ่านตัวดึงข้อมูลทั้งหมดและ generic extractor ของ yt-dlp
รายชื่อทั้งหมด: https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md
ใช้ลิงก์คลิปโดยตรง; ลิงก์ช่องหรือเพลย์ลิสต์บางชนิดอาจดาวน์โหลดหลายรายการ

Cookies
ค่าเริ่มต้นไม่ใช้ cookies เลือกเบราว์เซอร์เมื่อคลิปต้องใช้บัญชีที่ล็อกอินอยู่
เมื่อเลือกไฟล์ cookies.txt จะมีช่องเลือกไฟล์แบบ Netscape แสดงขึ้นมา
หากอ่าน Chrome/Edge ไม่ได้ ลองปิดเบราว์เซอร์ ใช้ Firefox หรือไฟล์ cookies
โปรแกรมอ่านไฟล์ cookies โดยไม่เขียนทับต้นฉบับ อย่าแชร์ไฟล์นี้ให้ผู้อื่น

สถานะงาน
หน้าจอใช้โทนกราไฟต์และทองอ่อน วางลิงก์แล้วกด Enter เพื่อเริ่มได้
ตัวเลือก Cookies อยู่ในปุ่มตัวเลือกเพิ่มเติม
ระหว่างดาวน์โหลดจะล็อกช่องตั้งค่า และแสดงความเร็วกับเวลาที่เหลือเมื่อมีข้อมูล
เมื่อเสร็จจะแสดงผลในหน้าจอโดยไม่เปิดกล่องข้อความ และเปิดโฟลเดอร์ของงานล่าสุดได้
แสดงกำลังเชื่อมต่อ เปอร์เซ็นต์ดาวน์โหลด จัดเตรียมไฟล์ เสร็จแล้ว หรือข้อผิดพลาด
เปอร์เซ็นต์เป็นของไฟล์ที่กำลังดาวน์โหลด อาจเริ่มใหม่เมื่อเปลี่ยนจากภาพเป็นเสียง
โหมด MP4 แปลงไฟล์ที่เป็นฟอร์แมตอื่นหลังดาวน์โหลด ซึ่งอาจใช้เวลา
หน้าจอเลื่อนได้เพื่อเข้าถึงทุกส่วนเมื่อหน้าต่างมีความสูงจำกัด
หากปิดโปรแกรมขณะดาวน์โหลด จะถามยืนยันก่อนหยุดงาน

ใช้เฉพาะสื่อที่คุณสร้างเองหรือได้รับอนุญาตให้ดาวน์โหลด
ไม่รองรับการข้าม DRM หรือสิทธิ์เข้าถึงของบัญชี
